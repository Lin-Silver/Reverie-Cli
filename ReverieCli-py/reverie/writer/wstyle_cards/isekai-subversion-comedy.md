# 创作目标与范围

在确认的穿越题材中，用角色的既有经验与新世界的实际规则之间的差异产生喜剧。已有项目如果没有穿越设定，只借用预期落差与喜剧因果，不能擅自添加穿越、系统或现代知识。世界规则、能力代价和人物知识边界始终有效。

# 喜剧因果

先建立人物为什么期待某种结果，再展示她的行动怎样触碰现实限制，最后让结果产生可理解的新麻烦或机会。读者应看懂错在哪里，人物也有机会修正认识。反转不是突然宣布所有规则无效，更不是把角色写笨后让她摔倒。

预期落差可以来自语言、制度、生活常识、技术条件或身份责任。现代知识只在材料、组织和成本允许时有效；主人公知道某项原理，不代表能一夜造出工业体系。当地人有自己的有效经验，可以纠正穿越者，也可以误解她的目的。

# 信息差与人物

明确谁知道什么。人物依据自己掌握的信息做合理选择，读者在必要时多知道一点，由此看见误会将怎样兑现。误会暴露后不能无限持续同一招；改变关系、资源或下一轮目标，让笑点产生剧情作用。

主角可以自信、狼狈或嘴硬，但不要永远靠旁白吐槽维持喜剧。对手、盟友和路人拥有各自目标，严肃人物也可能因为规则执行得太认真产生幽默。人物不能只负责接梗，笑点之后仍要承担自己的决定。

# 类型与反套路

借用读者可识别的类型期待，然后从已设定的限制中偏转结果。例如“传说中的勇者待遇”实际包含一项重要义务；偏转之后仍要给读者有价值的新理解，不能只说“原来没用”。轮换笑点来源：身份误读、实物细节、目标冲突、认知修正或前文回收，避免每场都用同一反转句。

# 语言、节奏与情绪

对白简洁地追求各自目的，关键反应落在动作与后果上。可以让严肃的语气衬出荒诞的制度，不必强加网络热梗。铺垫需要清楚，兑现后给人物和读者一点反应空间；不要每句话都解释为什么好笑。

危险、损失和受伤有真实重量。笑点可来自应对过程，不轻易消除事件的代价。轻喜剧也允许真诚、安静和关系修复，情绪回报不必被下一句吐槽立刻破坏。

# 原创示例

陶青见到“勇者免费住宿”的木牌，终于敢把铜币放回袋子。

店主给她一把扫帚。

“我住一晚。”她提醒。

“所以只扫一层。住三晚的还得上屋顶。”店主指了指牌子背面，“城里的勇者，都是带薪轮值。你的名册呢？”

陶青翻遍口袋，只找到报名时领的号码。她把扫帚立好：“先教我怎么下班。”

店主笑了一声，抽出另一张表。这回她先看了背面。

# 应避免与局限

避免强行降智、无依据的偶然解围、连续相同的打脸和现代热梗堆砌。检查每个笑点是否推进人物或改变条件；本卡提供可尝试的机制，实际幽默感须由具体文本和读者判断，不能用反转次数证明。
