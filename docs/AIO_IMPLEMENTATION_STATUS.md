# AiO 当前实现与验收状态

本次是 AiO 与全模式独立对话的源码更新检查点，目标分支为 GitHub `main`。本次不新增版本标签，包元数据仍为 2.5.3。

代码检查点 [630db11](https://github.com/Lin-Silver/Reverie-Cli/commit/630db11c99bbe8c5cfbd44efa0a826064e48f9a7) 与验证工具／文档 [6998930](https://github.com/Lin-Silver/Reverie-Cli/commit/6998930b9659ce0d8b38f955f15d76859ae0634a) 已正常推送到 `main`，远端提交身份已核对。源码发布不替代下述完整稳定性验收。

## 已实现

- AiO 替换旧 Computer 模式入口，使用自己的模型选择、稳定主线、阶段摘要、任务分支、主动发言队列、完整正文回复窗和暂停／恢复／停止控制。
- 所有模式保存独立对话配置，模型目录及凭据保持共享；桌面端已有任务固定入队配置，切换工作区和对话后继续执行。
- 消息、配置版本、任务关联和流片段使用 SQLite 事务保存，支持分页、重启恢复和旧 JSON 分批迁移，原文件保留。
- 桌面端普通任务与 AiO 共用最多四个执行槽位；Git 写任务在隔离工作区执行，普通任务成功完成后汇入，带验收条件的任务通过额外验证后汇入。汇入仅包含相对基础快照的变化，重叠冲突保留结果和用户修改。
- AiO 长期记忆支持查看、纠正和删除，导出包含任务／验收记录以及配套事件 JSONL。
- 保留已保存消息和文件原文字节、展开的历史分页，以及工作区记忆的当前请求上下文；记忆缓存通过原子替换发布。

使用与迁移说明见 [AiO 与独立对话](AIO_CONVERSATIONS.md)，电脑接口见 [Computer Use](COMPUTER_USE.md)。
