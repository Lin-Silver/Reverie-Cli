# 创作目标与范围

让多位重要女性角色在共同环境中有独立生活、判断和后果。群像不是角色收集，也不预设每个人都与同一主角恋爱。人物数量、核心成员和关系性质遵守项目设定；本卡调整组织方式，不自动扩充演员表。

# 叙事权重

确定全书主线与当阶段真正面对问题的人。核心角色承担持续弧线，次要角色有具体目标但不必全部分配独立视角。每章聚焦少数人物及她们正在改变的关系，其余角色可以离场继续行动，后续交代行动的成果或代价。平衡看关键选择、因果贡献和弧线回收，不按平均台词数分配篇幅。

# 独立性与功能

重要人物至少拥有当前目标、所知信息、可用资源和不能接受的代价。她们可以拒绝共同计划，也可能在主线之外遇到难题；不要只在主人公需要帮助时才出现。角色功能应从经历和能力中产生，不能让“智囊”“治疗者”“气氛担当”成为没有内在需求的职位标签。

在同一场景里，人物对同一问题的关注点不同：有人计算时间，有人保护证据，有人担心公开信息的后果。通过这些不同的选择区分人物，避免只换发色、口癖或称呼。

# 关系网络

除了每人与核心人物的关系，还维护成员之间的重要连接：合作、欠情、隐瞒、竞争、信任和分歧。关系发生变化后，应影响下一次信息共享或行动分工。不要让所有人都同意同一人，也不要为了制造内斗让专业角色突然失去判断力。

多人对白围绕各自目的推进。可让意见经过修正形成共同方案；每人说一句相同的惊讶或赞美不能形成群像。引入新人物时先展示一项实际选择及其代价，再根据需要提供履历。

# 阶段焦点与主线

一个事件单元可以让此前次要的人物成为焦点，但她的目标需要与当前主线发生可解释的联系。她解决个人问题后，集体的资源、边界或关系应改变。轮换焦点不是轮流插入无关番外；未处理的个人线应有位置和回收范围，避免人物越多越没有主线。

# 文笔与节奏

多人场景先交代空间、谁能听到什么和谁正在做事，避免代词指向混乱。旁白只解释当前决策需要的信息。高潮允许不同成员在不同位置作出互相影响的选择；收束时让成果和损失落到具体的人，不用集体欢呼替代情绪余波。

# 原创示例

临时议事桌上只有一盏油灯。周砚先算完仓里的麦，说还能撑六天；唐棠把药瓶推过去，改成了四天。

“外队要的是修好渡口，不是我们的药。”许禾说，“我可以拿工期换粮，但你们得把伤员名单给我。”

唐棠合上名单：“姓名不给。人数和需要的剂量，我陪你去谈。”

周砚在账页上空出两行，写下了新的条件。她们没有同意同一件事，却终于能一起出门。

# 避免事项与局限

避免用数量制造存在感，避免人物被主线遗忘，避免每位女主都只围绕一人的认可行动。本卡提供结构提醒，实际群像平衡需要跨章阅读；单章角色提及次数不能证明人物立体程度。
