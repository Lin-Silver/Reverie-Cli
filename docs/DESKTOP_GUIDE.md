# Reverie Desktop 使用指南

本指南按 2026-10-06 的本地 2.5.0 代码核对。当前完成度和边界见 [功能状态](FEATURE_STATUS.md)，终端命令另见 [CLI 参考](CLI_COMMANDS.md)。

2026-10-20 续修源码已加入自动交互视图选择指导和思考 Markdown 空白排版修复，但尚未重新打包；现有同版本安装包不会自动包含这些改动。Cloud 接手范围、测试失败和旧包证据见 [交接记录](CLOUD_CODEX_RIU_HANDOFF.md)。

## 启动与更新

Windows 构建提供 `Reverie-Portable-2.5.0-x64.exe`、`Reverie-Setup-2.5.0-x64.exe` 和终端核心 `reverie.exe`。下载 / 发布入口在 [项目 README](../README.md)。便携版首次启动需要解压运行时；包内桌面核心与外部单文件核心是不同启动路径。

便携版在自身目录下保存运行时和配置。深层目录中的内置 Skill 也应完整解压；写入失败会以退出码 2 停止，只有全部文件写入后才保存完成标记。更新启动器会更新缓存身份，首次启动可能重新解压运行时；请保留足够磁盘空间。解压、核心启动和恢复视图的总等待不等于模型生成或单个视图的渲染耗时。

已有安装版的快捷方式仍指向原安装目录。使用新便携包，或安装新安装包后再使用安装版；不要仅凭相同的 `2.5.0` 版本号判断二者是否来自同一次构建。图形 / 终端启动偏好在设置中，`ReverieUI.exe --gui` / `--tui` 可临时覆盖。

设置 → 关于显示界面构建 ID、构建时间和实际启动文件，可用它确认重新打开的是哪一份包。构建 ID 与版本号分别显示。

## 输入和上下文

- 在左侧选择项目和会话。文本与附件草稿按项目、会话独立保留；新会话使用独立草稿。
- 输入 `@`，使用上方候选引用工作区文件或符号；上下键选择、Enter 接受、Escape 关闭。附件按钮、拖放和图片粘贴也可加入文件。
- 附件必须处于就绪状态才能发送；每条最多 20 项、总量 200 MiB。工作区引用和复制的外部文件保留各自来源，缺失 / 变化时提示重新确认。
- 左下角选择工作模式；模型和思考能力在顶栏。波形按钮切换流式输出并立即反馈，后台保存失败时恢复原设置；运行中切换在下一轮生效。真实视觉理解仍取决于所选模型和线路。
- Enter 发送，Shift+Enter 换行。中文组合输入有防误发逻辑，但原生 IME 完整实机验收仍未完成。

## `/` 指令的真实边界

候选列表复用终端命令目录，**出现候选不等于 Desktop 能执行该终端指令**。

| Desktop 当前直接处理 | 行为 |
| --- | --- |
| `/model`、`/setting`、`/settings`、`/mode`、`/permission`、`/provider [list\|status]` | 打开设置 |
| `/mode <模式>`、`/permission mode <default\|auto_check\|strict>` | 通过核心设置接口修改；失败时保留草稿，运行中需先停止任务 |
| `/tools`、`/rats`、`/tasks`、`/operations`、`/plugins` | 打开对应页面 |
| `/checkpoints`、`/rollback` | 打开恢复页面；不直接执行终端子命令 |
| `/skill` / `/skills` 与固定、解除、清空子命令 | 打开 Skills 或改变会话 pin，详见 [Skills](SKILLS.md) |
| `/compact [附加要求]` | 请求核心压缩；运行中不能发起 |
| `/review ["文件路径"] [--scope working\|staged\|commit\|branch\|round] [--base "基准"]` | 打开工作面板审查页并保留文件、范围和基准；指定文件必须在实际差异中 |
| 其他候选及参数化终端指令 | 标为“终端参考”；发送时显示明确错误并保留草稿，不进入 agent |

命令面板支持上下键、Enter 选择和 Escape 返回原焦点；组合输入期间 Enter 不选择候选。需要其他终端子命令时在 Reverie TUI 执行。Desktop 不提供任意 TUI 命令执行器。

## 运行期间追加与恢复

运行中仍可编辑下一条草稿。Queue 在当前轮完成后发送；Steer 在核心安全点补充当前任务，Ctrl+Alt+Enter 可发起 steering。Stop 会直接取消当前模型连接、响应头等待、响应体 / 流读取和重试等待；已进入的工具动作仍在安全边界停止。强制停止会终止核心，可能留下未完成动作，恢复时先检查真实文件和进程。

持久队列在重启后暂停，需显式继续。会话继续以最后保存的记录为准，不自动重放外部工具；历史工具缺结果会标记可能中断，不能当作后台仍在执行。同一 Git checkout 的父目录、子目录及路径别名共享写锁，最多 4 个内核；独立 worktree 可并行，两个只读审查可并行。

思考默认显示正文，可点击摘要折叠；可靠时长没有保存时只显示“已思考”。对话标题栏和设置均可调整显示偏好。模型只返回思考、未给出答案的失败尝试也保留在历史中，包括中断前已收到的原生思考；失败提示不代表已经完成任务，也不会把原始思考改成成功答案。不会按“像内部指令”或“与回复重复”等内容猜测删改原生思考；未完成的工具参数不会因此成为可执行调用。

## 用户名称和头像

打开 **设置 → 对话显示**，修改“显示名称”后点击保存。上传头像支持不超过 20 MB 的 PNG、JPEG、WebP 或 GIF；拖动照片选择区域，通过缩放和位置滑块细调，也可用键盘调整滑块。点击“保存头像”只保存选中的 256 × 256 PNG 区域；取消或 Escape 保留原头像，“移除头像”恢复名称首字。

名称和头像属于本地桌面显示偏好，刷新 / 重启后保留。用户消息及头像排列在右侧，模型回答排列在左侧。完整的打包应用验证和请求性能边界见 [修复报告](VERIFICATION_HISTORY.md#reverie-cli-request-profile-repairs-2026-10-05)。

## 工作面板有什么用

顶栏的工作面板按钮打开统一右侧栏。拖动左边缘调整宽度；分隔线也支持左右方向键、Home / End 和双击恢复默认宽度。宽度偏好会保存，窗口缩小时临时收窄；窄窗口使用可关闭的覆盖面板。面板开合和菜单有短动画，并遵循系统的减少动态效果设置。

工作面板包含：

| 页面 | 用途与边界 |
| --- | --- |
| Git 改动 | 工作区、暂存区、提交、分支基准、AI 轮次 diff；文件 / 区块操作；整个暂存区提交；确认计划后的普通 push。状态筛选显示“已修改、已新增、已删除、已重命名、已复制、未跟踪、冲突”，附带 Git 字母 |
| 文件 | 按需展开的目录树；点击查看文本 / Markdown / 图片 / PDF / 静态 HTML；支持 UTF-8 文本编辑和 Ctrl+S 保存。HTML 预览不执行脚本或联网 |
| 只读审查 | 选择实际差异范围 / 文件后请求模型审查，保存原文与可解析发现；不自动修改代码 |
| 运行与终端 | 独立工作目录、用户 PTY、项目动作、运行记录、计划、通知、生效能力 |
| AI 改动 | 当前会话通过文件工具产生的改动 |
| 上下文 | 当前工作区和会话的上下文信息 |
| 活动 | 当前会话的运行活动与工具事件 |

编辑保存保留 UTF-8 BOM 和 LF / CRLF 格式，检查打开时的磁盘版本。文件被外部修改时拒绝覆盖并保留草稿；换文件前可选择保存、放弃或取消。切换面板标签和折叠右侧栏保留未保存内容。草稿只在本次应用运行中保留，退出前应保存。单文件编辑上限 2 MiB；二进制、其他编码或混合换行文件使用只读预览 / 系统编辑器。模型任务运行时暂不可保存；工作区外的符号链接不可打开。

Git 目录项应作为项目打开，不能当文件读取。撤销、删除、提交、推送和动作运行均有具体范围 / 确认；工作面板没有 PR / CI 管理。用户 PTY 使用当前用户权限，与只读模型审查的工具白名单不同。

“目标与计划”保存后会在所属会话下一轮执行开始时注入模型，包括排队任务；运行中修改仍通过 Steer 更新。只读审查不注入普通执行目标。步骤的“验证通过”是用户标记，不是后台自动验收；计划不会自行执行或无限循环。

文本预览和 diff 使用流式读取，每页最多 2000 行 / 2 MiB；单行超过 256 KiB，或图片 / PDF 超过 20 MiB 时提示使用系统打开。为了核对完整哈希和总行数，当前每页仍需扫描数据流。终端 / 运行日志最多保留当前及上一份各 8 MiB，恢复最多 1 MiB，截断或突发事件丢失会明确标记。

历史搜索使用工作区独立的 SQLite 缓存，首次建立索引需读取旧会话；之后只更新变化的会话。短查询或没有 trigram 支持的 SQLite 使用缓存内扫描。审查输出只有合法 JSON、有效字段和属于已捕获 diff 的文件 / 行号才进入发现列表；格式错误保留原文并显示错误。只读审查使用独立完成规则，不要求改文件 / 跑测试，不因缺少编码动作自动续跑。

## 直接调整对话内容显示

对话标题栏的眼睛按钮提供“全部内容”“思考与回复”“仅模型回复”三个模式，并可分别开关思考、工具调用、工具结果和实时活动。默认显示全部内容。设置 → 对话显示使用同一组偏好，刷新和重启后保留；只隐藏页面内容，不删除会话记录，也不减少下一轮发送的上下文。

流式请求会复用内核和连接池；桌面初始化后会在空闲时预备一个请求内核，不发送模型请求。首次内核初始化与 Git 快照并行；文件内容和父提交相同的连续快照复用已有 Git 对象，各轮仍保留独立恢复引用。服务商返回响应头、首个流事件和正文的时间仍由实际线路决定，详见 [工作面板与请求验证](VERIFICATION_HISTORY.md#reverie-cli-workbench-repairs-2026-10-06)。

## MCP 交互视图

RIU 视图标题栏提供三种展示位置，和对话内容显示偏好共用 `ConversationDisplay` 控件：

| 模式 | 操作与行为 |
| --- | --- |
| `inline` | 在对话内操作；“返回对话内”回到原位置并恢复宿主按钮焦点 |
| `fullscreen` | “在工作面板中放大”打开 Workbench 的交互式视图页签；正常聊天输入框继续可用 |
| `pip` | 右上角画中画持续显示当前视图；可继续聊天、切回 inline 或放大 |

`card`、`carousel` 是 HTML 内容布局，不是桥的 display mode。组件通过标准 `ui/request-display-mode` 请求以上三种模式；未知模式返回参数错误。位置切换使用 Electron 的原子 DOM 移动，保留同一 iframe、脚本实例、表单值与内部滚动，不重新请求模型或解析视图。同时最多有一个放大/画中画视图。

画中画提供更大的内容高度，摘要默认为紧凑单行，可显式展开全文。生成内容仍须按窄视图组织主结果与关键控件；宿主增加高度不能保证任意页面无需滚动。摘要应说明用户可看的结果和可做的操作。

实时回复转入历史记录时，同一项目/会话/视图/revision 也共用原实例；不会等模型结束后再重建一份组件。返回 inline 时恢复 Workbench 原来的开关与页签，避免空面板遮挡窄窗对话。

宿主按钮支持 Tab、Enter、Escape；视图内按 Escape 也可返回 inline。关闭 Workbench 时焦点回到输入框。窄窗放大面板为输入框留出空间。亮暗主题、语言、尺寸通过初始 `hostContext` 和 `ui/notifications/host-context-changed` 更新，组件应应用 `styles.variables`；生成视图还可读取 `hostContext.reverie.reducedMotion`，这是 Reverie 扩展字段，标准组件仍可使用 CSS `prefers-reduced-motion`。这些更新不重建 iframe。

长历史仍分页加载，每页 60 条消息；视图仅在可见、聚焦、执行工具或放大/画中画时挂载。离屏、收起及离开会话会撤销通道、执行租约、资源 token，并释放宿主监听器、观察器和计时器；帧销毁也停止其动画和计时器。内置视图应通过 `reverie/view-state` 保存筛选、页签等私有状态，恢复时从 `reverieViewState` 读取；未主动保存的组件临时状态在销毁后无法恢复。这个限制不影响三种展示位置之间的状态保持。

宿主仅把展示位置/展开偏好保存在按项目、会话、视图和 revision 区分的 Desktop 设置，最多 200 条，不包含 HTML、业务数据或组件私有状态。浏览器存储只作缓存；清空缓存或重启后从桌面设置恢复，核心和纯文本客户端不依赖 localStorage。刷新/重启恢复已保存偏好与私有状态，不重放工具。缺文件、过期实例和超时保留摘要并给出重试提示；先核对未知写操作的实际结果再重试。

声明标准 UI 资源的 MCP 工具可在对话中显示离线组件。缺失资源、错误 MIME、过大 HTML 或要求外部网络/浏览器权限时，工具仍返回文本结果；当前 profile 不自动授予这些权限。收起组件会撤销工具执行权限并尝试标准 teardown。

组件工具调用使用原有宿主审批与 Stop；组件内的按钮不能代替宿主审批。组件发出的追问只显示建议，点击宿主“发送追问”后才进入模型。私有结果 `_meta` 不进入对话或模型；组件主动提供的文本/JSON 摘要作为不可信 user 数据加入下一轮。

重新打开会话可以查看已保存快照。若原 MCP worker 空闲回收或连接已替换，旧组件的工具调用会报告连接过期；重新调用原工具生成新绑定。重载旧 HTML 不会自动重放写操作。当前固定 ext-apps 2.0.3 / UI 协议 2026-01-26；精确支持、拒绝与未验证范围见 [协议矩阵](INTELLIGENT_UI_SPEC.md#p3-固定兼容-profileoffline-server-tools-v1) 与 [P4 本地展示/性能及交付验证](VERIFICATION_HISTORY.md#riu-p4-delivery-2026-10-17)，不声明全部 `window.openai` 或 Plugin Extensions 兼容。

长视图摘要默认折叠，点击“展开摘要”可以查看全文，再点击“收起摘要”恢复紧凑显示。这个操作只改变摘要显示，不重新运行视图或清空控件状态。
历史中的展开视图只在滚动到可见区域时加载；占位保留视图高度，避免相邻视图加载后把当前阅读位置推走。

## Skills、扩展与数据

Skills 页面用于搜索、固定、解除和查看来源；默认模式有 17 个内置 Skill，其中 14 个来自 Emil Kowalski。固定项随所属会话保存，分叉 / 自动轮换继承，普通新会话清空，CLI 和 Desktop 均恢复。每轮由核心读取固定 Skill 完整正文；遵循工作流的模型行为仍需实际检查，详见 [Skills](SKILLS.md)。

插件“已安装 / 启用 / 信任”、MCP“发现”和 RATS“登记 / 连接 / 授权”是不同状态。只有实际授权且提供有效工具的服务才能被 agent 调用。

数据有多个位置：核心配置 / 会话在 app-root 缓存，桌面运行记录 / 用户终端 / 目标及部分附件在工作区 `.reverie`，界面偏好和草稿使用桌面存储。迁移或备份前参阅 [配置与数据布局](CONFIGURATION.md)，不能只复制一个目录。
