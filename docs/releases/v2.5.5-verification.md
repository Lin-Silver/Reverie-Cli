# Python 2.5.5 release verification

Version 2.5.5 closes out the current Python product while preserving its directory layout, Electron desktop, existing features, and bundled Rust Context Engine. The stable release tag identifies the complete-project baseline for a future `Reverie-Cli-py` archive. This release does not switch the mainline to Rust or introduce the Rust rewrite.

The release was authorized against a narrowed acceptance scope: full software regression, real compilation, native package checks, frozen CLI/SDK tool effects, and controlled real-provider Writer verification. Local virtual-machine work and host foreground interaction were stopped. Earlier requirements outside that scope remain unverified and are explicitly listed below.

## Preserved failures and limits

- The first Desktop run timed out during a worker startup handshake. The affected 122-test module and an unchanged complete 527-test rerun passed. The startup long-tail root cause is not established.
- The baseline Intel native input test failed at p95 160.5 ms with 60 samples against the original 100 ms gate. A same-package diagnostic at 94.8 ms did not replace the failure. The unchanged complete job rerun passed at 93.4 ms. The long-tail root cause is not established.
- One real SenseNova review returned malformed JSON. The product rejected it and preserved the manuscript and diagnostics. A complete repeat using the identical request SHA passed; successful repetition does not guarantee provider output reliability.
- An earlier private Writer verifier incorrectly required the whole novel-directory file set to remain identical after review. It counted the expected new review artifacts as manuscript changes. The corrected verifier still requires every pre-existing file to remain byte-identical and permits only the exact expected new evidence files. Original failed attempts remain retained.
- Native CI uses synthetic loopback model fixtures and has zero model-quality samples. Its software, package and performance verdicts do not rate real-model task quality.
- Independent reading of the generated chapter found a missing causal step for replacement-rope delivery, inconsistent lighting details, and repeated endings after append-only continuation. Literary quality was not accepted. The chapter did not reach its 10,000-character target; the novel was not completed.

The following earlier acceptance work was not completed for this release: a fresh single continuous 28,800-second package run; full real-provider AiO scheduling, switching, recovery and memory product flows; final-package Computer Use foreground/visual/physical-input and cancellation flows; real mixed-DPI physical multi-monitor testing; complete clean-host install/portable/old-data recovery/uninstall acceptance; all remaining real-provider RIU and Writer desktop flows; and the full multi-sample and complete-novel literary evaluation. Historical evidence from older source/package identities does not turn these into final-package passes.

Release publication and the archive baseline use the explicitly narrowed software/build/tool scope above. Existing feature contracts and failed evidence are preserved. Back up existing configuration, conversations and manuscripts before upgrading. Reverting to a previous published binary is available if a product regression is encountered; backups preserve data independently of that binary choice.
