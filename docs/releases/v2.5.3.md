# Reverie v2.5.3

Reverie CLI / Desktop 2.5.3 汇总 v2.5.0 正式标签之后的累计更新，重点是可切换的 Liquid Glass 界面、RIU 富格式回答、工作台、RATS/RTP，以及提供商、会话和跨平台发布可靠性。

## 与 v2.5.0 的明确区别

比较基线为 `v2.5.0`（`9035bc861054a76690ca765ac27492cc41c35038`，2026-07-17 发布）。发布说明编写前的源码核对终点为 `08481399f548da699b8940bbc97801fd77f68188`，两者之间有 99 条提交；本次发布再加入 changelog 和本说明。不是仅比较最近一次 UI 提交，也不是把历史“仍为 2.5.0”的开发记录当作旧正式安装包已有的功能。

| 方面 | v2.5.0 正式标签 | v2.5.3 的变化 |
| --- | --- | --- |
| 桌面外观 | 原有桌面界面 | 新增经典/Liquid Glass 切换、玻璃材质、独立外观偏好及无障碍外观；修复侧栏动画、工具栏对齐、背景、输入框边线和弹窗圆角 |
| 消息与富回答 | 原有聊天及 Markdown 展示 | 新增 RIU 指标卡、表格、图片推荐、状态徽标、来源/链接和响应式布局；交互视图增加状态恢复、MCP Apps profile 与生命周期隔离；助手头像更新，用户消息只显示头像 |
| 桌面工作台 | 基础项目/对话和工具入口 | 扩展 Git 审查、运行终端、上下文、活动、结构化输入与可恢复任务轨迹；优化长对话及会话切换 |
| 外部工具服务 | 尚无本版新增的 RATS/RTP 模块 | 新增 RATS 提供方发现、能力协商、动态原生工具目录和 RTP 任务工作区/生命周期；当前外部提供方实现为 Reverie Engine，不代表所有提供方已接入 |
| 模型与图像 | 已有多提供商及图像能力 | 新增 `/provider` 自定义网关、按模型记忆上下文窗口、思考兼容处理；更新目录、流式/工具/取消重试路径；Desktop 增加图像模型选择，扩展 SenseNova 编辑 |
| 上下文与会话 | 已有 Context Engine、会话、记忆和压缩 | 修复并行索引/检索边界、活动会话重载及保存；统一实际请求与界面上下文统计，优化发现缓存和闲置内核回收 |
| 技能与内置 Engine | 已有技能及 Python 游戏/场景运行时 | 增加带来源和许可证的设计/动画技能、技能固定和覆盖提示；Python Engine 增加原生窗口及输入/缩放/关闭路径，与外部 Engine 编辑器接入分开记录 |
| Windows CLI | 已提供 CLI EXE 与桌面内核兼容机制 | 强化独立单文件 EXE，验证无相邻运行时目录时的握手与 SDK 桥接；桌面仍保留编译回退内核 |
| 发布与 CI | 已有四平台产物、内核协议/哈希校验 | 修复 Git 2.56、Linux 输出目录/启动器/权限、上游字节校验和原生测试环境；保留四平台聚合与附件校验 |

跨平台安装包、浏览器控制、电脑控制、`--kernel-info`、受信任外部内核和 SHA-256 校验并非 2.5.3 首次引入。提供商目录变化也不表示列出的每个模型都通过了实际工具调用、视觉、思考或完整 SSE 验收。

## 验证与已知边界
