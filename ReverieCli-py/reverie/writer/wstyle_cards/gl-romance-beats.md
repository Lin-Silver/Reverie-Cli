# 创作目标与边界

组织女性之间具有主体性的情感关系。浪漫由双方各自的愿望、理解与选择产生，不把某人写成另一人的奖赏。人物身份、年龄、关系进度和已有承诺由小说设定决定；本卡不会自动把友谊改成恋爱，也不会改变用户明确要求的关系性质。

# 关系从具体互动生长

每次重要靠近应有可指认的原因：一个人记住了对方说过的需求，尊重了她的拒绝，或在有代价的时刻兑现了承诺。这些互动改变对彼此的判断，再影响后续选择。不要仅靠外貌吸引和旁白宣称好感来跨越信任缺口。

双方表达情感的方式可以不同。有人愿意直说，有人先把时间留出来；含蓄表达要让读者有足够线索理解，不能无限延迟沟通。直接表达也可以细腻，因为回答、迟疑和下一步行动仍有层次。

# 认知差异、边界与冲突

允许双方知道的信息不同、对同一帮助有不同解释。误会来自具体处境和经历，并在可沟通的机会里逐步澄清；不能让人物集体拒绝问一句话，只为拖延关系。分歧也可以来自价值、职业、家庭和个人目标，必须说明代价。

尊重拒绝、隐私和协商。亲密关系不能取消人物的事业、朋友和独立判断。和解需要发生新理解或行为改变，不把一次拥抱当成消除所有旧伤的按钮。信任增长、受损和修复都应留下跨章可追踪的影响。

# 情绪的积累与回报

让早先不起眼的行为在后来获得新的意义，例如曾经保留的空座、记错又改正的习惯、一次没有被追问的沉默。回报可以是主动请求帮助、坦白需要、协商未来或允许对方看见脆弱，不必每次升级肢体亲密。承诺兑现后允许安静余波，让人物感受变化。

关系的发展不是固定的“认识—误会—吃醋—告白”顺序。依照人物当前目标安排推进或停顿，有时分开完成自己的事也会让关系更有重量。

# 文笔与对白

优先写具体动作、选择与回应，心理叙述补充读者无法从表面获得的信息。对白中的照顾、试探或拒绝要保留当下目的，不让所有人物用同一种温柔句式。避免旁白不断解释“她们都心动了”，让读者从行为变化理解。

# 节奏与应避免的问题

情绪和关系章可以是主要事件，允许慢场景，但场景结束后理解、边界或期待应有变化。避免突如其来的占有欲被当作爱情证明；避免把同性关系固定成刻板的强弱角色；避免只有暧昧没有个人成长，或把其他女性统一写成竞争对手。

# 原创示例

沈南竹说不想过生日时，陆晓没有再问蛋糕的口味。

那晚收工，桌上只有一碗平常的面。陆晓把遥控器递给她：“今天你挑。”

沈南竹握着遥控器，过了好一会儿才说：“明年可以问我一次。”

“一次？”

“嗯。到时候我也许会换答案。”她低头拌面，给陆晓留出了半张沙发。

# 自查与局限

核对每次关系变化是否有互动依据，是否保留双方的独立目标与边界。本卡提供关系机制，无法用告白次数、对白比例或亲密场面数量判定情感真实度。
