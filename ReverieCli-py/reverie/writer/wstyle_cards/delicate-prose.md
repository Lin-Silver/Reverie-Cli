# 创作目标与范围

让读者从人物看见、忽略、触碰或迟疑的事物中感到情绪。细腻来自观察的准确和变化的累积，不能由形容词数量替代。本卡调整表达，不改变已确定的事实、视角、角色身份和项目风格指南；当前明确的写作要求优先。

# 叙述原则

在每个重要场景里选一两个与人物处境有关的细节，让它们随事件改变意义。例如开始时令人安心的脚步声，争执后可能变成不愿回头的理由。不要把每件家具都写成象征；有信息、情绪或空间作用才保留。

限知叙述从当前人物能感知的范围展开。她可以误解他人的停顿，叙述不要立即跳入另一人的内心解释真相。情绪强烈时先写身体、注意力或动作的变化，再在有必要的地方给出简短判断。直接说出感受并非禁忌；重复解释已经表现出的感受才会消耗张力。

# 句式与语言

使用自然、具体的现代中文。动作发生时缩短句子；需要连续沉浸的观察可用较长句，但保证主语、动作和空间关系清楚。短句承担停顿或重点，不要把所有句子切成相同长度。比喻应来自人物的经验，帮助理解当下的感受，不堆叠互不相干的意象。

区分物理细节和抽象评价。与其反复说“温柔”，可以写对方把打断的问题留到饭后，或在她伸手之前挪开烫杯。避免每段用“仿佛”“似乎”“不由得”模糊动作；这些词可以出现，具体语境和重复程度决定是否修改。

# 人物与对白

对白有当下目的，也有未能说出口的部分。用人物关注什么、避开什么、如何回应问题区分声线。让停顿、打断、换话题和手边动作承担关系信息；不要给每句对白附上心理解说。允许人物直接表达需求，克制不等于永久含糊。

# 节奏与章节

安静的场景可由一次认知或关系变化完成推进，无需强加危机。重要选择之前留出感知和犹豫，选择发生后展示实际后果。日常过程没有新的意义时压缩，情绪回收时给读者停留的空间。描写密度由本章功能决定，不规定固定对白比例或每段感官数量。

# 应避免的问题

不要把同一个感受换三个近义句再说一遍；不要让旁白比人物更急着总结关系；不要连续以景物抒情代替人物行动。人物的细微反应要与过去的经历和当前事件相符。情绪细腻不能掩盖因果断裂、场景空间不清或无意义的拖延。

# 原创示例

乔沅把第二只碗从柜子里拿出来，又放回去。门外的钥匙转了一半便停住了。

“汤还热着。”她说。

程栖没有问那只碗为什么沾着水。她脱下外套，先把湿袖口折进掌心，才伸手去接乔沅递来的勺子。碗沿碰了一下，轻得像一个还没说稳的答应。

# 自查与局限

检查细节是否改变了人物、读者或场景的理解，删去只提供装饰的重复段落。本卡是表达机制建议；样本中的细节选择和慢场景效果仍需结合具体作品编辑，不能证明商业阅读表现。
