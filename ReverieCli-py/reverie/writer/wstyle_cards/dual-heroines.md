# 创作目标与边界

组织两位核心女主共同承担故事的双主角结构。她们都能作出影响事件的决定，也都要面对决定的代价。双女主不预设爱情、敌对、身份对称或平均字数；是否存在情感关系由项目事实和其他关系 Card 决定。不得为了套用结构凭空增加或删除已有主角。

# 独立的人物发动机

为两人分别保留当前目标、长期需求、可支配资源、恐惧或底线、知识盲区。共同任务之外，她们应有不能轻易被另一人代替的生活和判断。共享场景先确定各自想得到什么，再让同一事件在两人的经验里产生不同意义。

一人主动解决问题时，另一人可以支持、拒绝、修正或付出另一种代价。支持也可以是有主体性的选择；关键在于她知道自己为什么这样做。不要让同一个人永久承担发现线索、救援和决策，另一人只负责惊讶或被保护。

# 视角与信息

遵守已确定的叙述视角。需要切换焦点时，在场景边界清楚标识，避免一句话内穿梭两人的心理。信息差来自接触到的事实、经验和关注点，不能让人物忘记刚发生的事来制造误会。重复呈现同一事件必须增加新的认知，不能只换一个名字复述。

# 关系对剧情的作用

两人的选择应相互改变条件：一人公开了秘密，另一人原来的计划便需要调整；一人坚持底线，另一人须面对被拒绝后的办法。允许共同目标与个人目标冲突，冲突有具体利益和历史依据。和解不要求一方无条件放弃自我，关系发展可以通过协商新边界完成。

# 声线与成长

用两人处理压力的方式区分声线。有人先核对事实，有人先观察人的反应；有人直说要求，有人习惯给选择。这些习惯可以在成长中调整，但改变应有事件依据。避免通过统一的标签对比把一人写成“冷”、另一人写成“热”，让她们在不同场景出现真实矛盾。

人物弧线可以异步推进。某一阶段突出其中一人时，另一人的目标仍应继续存在，并在适当时刻产生后果。双主角平衡看决定的重量和成长的连续性，不看出场段落是否相等。

# 节奏与避免事项

关系场景也可以推动主线；外部事件也应影响双方的资源、信任或选择。避免轮流受伤、轮流救援成为唯一结构；避免每次分歧都被偶然事故中断。阶段结束时交代两人各自获得或失去了什么，下一步由这个变化产生。

# 原创示例

林见雪要留下被划掉的测量记录，向岚要先让工人撤出旧桥。两人争了三分钟，谁也没把对方说服。

向岚最后把钥匙放到记录本上：“你锁资料室，我锁桥门。等人都出来，我陪你找那张原表。”

林见雪按住钥匙，没有立刻点头：“你得告诉他们，撤人是你的判断，不是仪器坏了。”

“可以。”向岚拿起扩音器。这一次，记录没有丢，桥上也没有再进去一个人。

# 自查与局限

检查两人是否都拥有不能互换的目标与有效行动，是否记得彼此作过的承诺。本卡支持结构设计，不能靠机械统计判定双主角塑造是否成功。
